# 按表格配置卡牌效果

已读取《卡牌效果.xlsx》Sheet1 第 2–27 行，接入全部 26 种效果。原工作簿未修改；表中 E 列的效果描述与 F 列的基础 X 范围保存到对应资产中。

## Unity 编辑入口

1. 打开 `Scenes/RainbowLiGame.unity`。
2. 选择 `GameSystems/CardSystem`，点击 Catalog：`Data/DefaultCardEffects.asset`。该效果池控制起始牌、战斗奖励、休息生成和商店指定数字生成。设置在卡牌模块上时优先于 DefaultGame 的引用。
3. 双击 `Data/CardEffects/CardEffect_01.asset` 至 `CardEffect_26.asset`，修改 Display Name、Description、Min/Max Value、Weight、Include In Starting Deck。Effect 为实际结算类型，Polarity 控制增益给自身、减益给对方；Lifetime 控制状态持续方式。直接伤害/护盾/治疗立即结算。
4. `Data/Cards/TableCard_01.asset` 至 `TableCard_26.asset` 是对应的手工卡牌模板；指定 Number 与 Effect Definition 后，可拖入玩家的 Starting Deck。关闭 Random Starting Deck 使用手工牌组，至少保留 6 张。
5. `Prefabs/PokerCard.prefab` 控制牌面样式。选中手牌会在反馈区显示完整效果描述；`BattlePanel/StatusSummary` 显示双方主要状态，PlayerSystem/EnemySystem 的运行时 Inspector 显示完整列表。

随机起始牌仍为 3 组数字 1–6，共 18 张。每组按效果池权重抽取效果，抽中过的类型降低权重；每张状态卡的基础 X 在表内范围中随机取整数。同一张卡的 X 生成后固定，抽牌、重新排列和预览不会重新抽 X。Uses Card Number 的 X 使用原始牌面数字。

## 取值与叠加

表内的伤害、防御、恢复使用数字 X；增值伤害为 1+X，减值伤害为 max(1,7-X)。这些卡牌不再加旧的基础攻击与 Base Bonus。升级仍增加卡效数值，表中范围约束基础取值；限伤、往复、无序默认禁用无意义的数值升级。原有 18 张手工伤害/防御/恢复资产也已改用对应表格效果。

- 力量增加造成的伤害；易伤增加受到的伤害。弱化/坚固为固定 25% 修正，层数决定持续时间，所有百分比取整均向下。伤害依次经过力量、弱化、易伤、坚固、单次限伤、招架和护盾。招架完全免疫一次有效伤害，保留护盾并显示格挡。
- 铁壁将每次获得的护盾乘 1.25，向下取整；层数决定持续时间。限制伤害按单次伤害上限实现，多次施加取更低上限，本场战斗持续生效。
- 中毒在回合结束造成层数对应伤害，再将层数减半向下取整。烧伤在回合开始造成层数伤害并减一层；再生回合开始恢复层数生命并减一层；壁垒回合开始获得层数护盾并减半。
- 流血在该角色执行每个实际行动前扣除层数对应生命，随后减一层。它直接减少生命，绕过护盾和伤害减免；若流血致死，该行动不再执行。插入数字和状态结算不额外触发流血。
- 点燃/淬毒在持有者每个实际行动后向对方施加烧伤/中毒，包括获得该状态的行动本身。牌序效果和往复产生的实际行动也参与；单纯插入数字不参与。

## 数字与重复效果

随机 X 在行动后追加 X 个随机数字，数字会参与牌序；追加数字不会再次触发“行动后随机”，避免自我无限生成。

无序对持有者的全部数字填入生效；变动消耗接下来 X 次填入，先随机为 1–6，再计算加值/减值。加减保留算术结果，可以为 0、负数或大于 6，不自动回绕；卡牌的伤害数值仍按原始牌面计算。变动包含刚施加该效果后该卡牌的数字填入。

吟唱令匹配的牌序效果额外执行 X 次；往复令实际行动额外执行一次，重复副本不会再因往复自行重复。往复重复沿用原卡牌动效位置。两者叠加时可重复卡牌和牌序效果；保留既有单牌序 99 次与单回合 4096 次结算上限。

战斗随机状态独立保存并复制到预测副本，因此调整顺序后，预览中的随机数字与同一安排的真实结算一致。预览不会改变牌组、状态、数字流或真实随机状态。

## 生命周期约定

临时效果默认本回合有效，回合结束清除；这是表格未说明清除时机时沿用的原型约定。持续效果按表中的触发/衰减规则运行；限伤没有自动衰减。所有战斗状态在新战斗或新游戏初始化时清除。

回合末先处理双方中毒，再减少弱化/坚固/铁壁、清除临时状态；下回合先重置护盾与原有临时强化，再按烧伤、再生、壁垒处理开始效果。开始/结束状态导致死亡时立即停止战斗。

## 模块边界

| 文件 | 职责 |
|---|---|
| Unity/Data/CardEffectDefinition.cs | 单效果 ScriptableObject，保存表格编号、描述、分类、X 范围和权重 |
| Unity/Data/CardEffectCatalog.cs | 可编辑效果池，复制到每局配置 |
| Domain/CardEffectSpec.cs | 纯 C# 效果配置副本 |
| Domain/CombatStatuses.cs | 双方独立状态、层数、持续方式与回合衰减 |
| Domain/ContainmentGame.Effects.cs | 卡效执行、数字变化、行为后效果、状态触发与战斗随机数 |
| Domain/ContainmentGame.Combat.cs | 行动队列、开始/结束结算与死亡判定 |

在非 Play 模式修改资产后重新 Play 或点击新的一局应用。旧 IMGUI 场景继续作为兼容参考，新入口使用上述效果池。

验证使用纯规则和 Unity 无图形批处理，覆盖全部效果、随机预览、复合连锁、配置加载、状态显示及路线流程；最终排版和动效节奏仍需在 Game 视图试玩确认。

现在可使用独立的玩家/敌人表格编辑器进行配表，入口为 RainbowLi > 配表。DefaultPlayerCards / DefaultEnemyCards 已分别绑定角色并优先于旧效果池；详见 [配表编辑器指南](CARD_EDITOR_GUIDE.md)。
