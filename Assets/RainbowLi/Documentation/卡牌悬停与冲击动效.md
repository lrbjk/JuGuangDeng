# 卡牌悬停与冲击动效

统一使用CardView的所有牌面（手牌、行动区、敌人技能、奖励、卡组、抽牌堆、弃牌堆、操作确认牌）支持悬停放大。不可点击的卡也能查看。
悬停预览放在根Canvas浮层，不改变源卡片排列、不受滚动遮罩裁剪，也不拦截点击。离开、开始拖放、隐藏源卡或打开覆盖弹窗时清除预览；拖牌仍按原交互操作。

## 策划调参

资源：Assets/RainbowLi/Data/DefaultBattlePresentation.asset。
- 悬停放大倍率：默认1.25；悬停放大时长0.12秒；悬停抬起距离22。
- 蓄力时长、攻击飞行时长、命中光圈时长控制蓄力→冲击→归位节奏。
- 蓄力后撤距离默认38，冲击倾斜18度，蓄力放大幅度0.18。
- 卡牌突进比例默认0.94，接近效果对象；1抵达目标中心。
- 飞行弧线高度控制冲击轨迹。伤害→视觉强度曲线、攻击连锁倍率继续控制大伤害和连锁表现。

攻击由卡牌本体执行：后撤蓄力、放大倾斜、加速冲向对象、命中闪光/震屏/飘字、返回原位。治疗、护盾和状态牌使用现有效果对象；牌序与状态结算继续使用光圈/投射物。悬停预览和战斗飞牌是纯表现副本。
在配置Inspector中进入战斗后可用“预览攻击”检查参数；预览不会扣真实血量。暂停、单步、倍速、长连锁加速、跳过和重开继续使用统一播放时钟。

## 代码位置

Scripts/Unity/Views/CardView.cs：统一悬停浮层、清理及点击穿透。
Scripts/Unity/Views/HandCardDrag.cs：开始拖放时移除悬停副本。
Scripts/Unity/Effects/CardMotionController.cs：卡牌蓄力、飞行、命中与归位。DuelCardPosition仅计算视觉轨迹。
Scripts/Unity/Data/BattlePresentationProfile.cs及Editor/BattlePresentationProfileEditor.cs：策划参数与中文Inspector。

验证：54项悬停/拖放/冲击检查，50项播放控制回归检查；已查看悬停与命中渲染画面。Domain结算和GameSession未修改。
