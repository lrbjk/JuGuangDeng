# 策划打击感调试器

菜单：RainbowLi → 动效 → 打击感调试器。
也可选择Data/DefaultBattlePresentation.asset，在Inspector点击“打开打击感调试器”。窗口优先载入当前场景绑定的配置，否则使用默认配置。

## 调整流程
1. 在六个分组中修改参数；可使用轻击、重击、夸张连锁预设作为起点。
2. 进入Unity播放模式，开始游戏并进入战斗，等待发牌动画结束，保持“安排行动”阶段。
3. 设置模拟伤害、连锁次数和是否命中玩家，点击预览。快捷按钮可对比5伤害轻击、60伤害重击和8次连锁。
4. 调整参数后再次预览，观察卡牌后撤、冲击、命中、闪光、震屏、粒子、飘字和音效。
5. 点击“清理预览 / 恢复原播放状态”，然后保存配置。关闭窗口或切换配置也会清理自己创建的预览。

预览自动暂时关闭自动播放，不执行卡牌规则、不扣血、不改变战斗随机数或真实伤害。运行中修改的是配置资产，退出播放也会保留；Ctrl+Z撤销，“还原打开时参数”恢复本次打开该资源时的快照，保存才写入磁盘。
应用预设不会覆盖音效资源、颜色、悬停放大或抽弃牌参数，且可以Undo。
如果当前场景未绑定选中的配置，可在编辑模式点击“将配置绑定到当前RainbowLi场景”。预览按钮只在绑定配置与窗口选中资源一致、战斗安排行动阶段且飞牌完成时可用。

## 六组参数
- 卡牌冲击：蓄力/飞行/命中时长、突进比例、后撤距离、倾斜角度、蓄力放大、弧线、伤害强度曲线。
- 命中反馈：粒子数量、持续时间、扩散、尺寸、飘字大小和位移。
- 震屏与闪光：开关、强度和持续时间。玩家设置若关闭震屏，预览也遵守这个设置。
- 音效与颜色：轻重击音效、音量和音调、攻击/护盾/治疗/状态及粒子颜色。
- 连锁与节奏：连锁倍率和增长速度、行动间隔、重复效果加速门槛与最大速度。
- 悬停与飞牌：放大与抬起、抽牌/出牌/弃牌时长、发牌间隔和旋转。

窗口代码：Editor/BattleImpactEditorWindow.cs。所有数值仍由Scripts/Unity/Data/BattlePresentationProfile.cs维护，同一资源可通过原Inspector编辑，不产生第二套配置。
