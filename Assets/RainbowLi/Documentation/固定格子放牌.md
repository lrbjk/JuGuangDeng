# 固定格子放牌

- 入口：`PokerActionLayout.fixedGrid`，默认开启；卡槽数量、大小、间距继续由该组件调整。
- 拖放：只接受鼠标所在的空格；格子间隙、敌人牌和其他玩家牌所在格拒绝落牌。
- 移动：桌上玩家牌可以拖到另一个空格；也可拖回手牌撤回。放置、移动和撤回不会挤动其他牌。
- 顺序：忽略空格，按卡牌从左到右执行；空格不是行动，不产生牌序数字。
- BOSS 锁定行动的限制继续生效，非法移动不改变原位置。
- 格位保存在 `BattleAction.BoardSlot`（一基编号，0 表示旧数据未初始化）并由 `RunSave` 保存。旧存档按原相对顺序初始化；新回合使用新行动重新排初始敌人位置。
- UI 提交入口：`CardModule.PlaceInBoardSlot`，拖放预览与实际落点使用同一个卡槽矩形。


## 敌方行动拖动

安排阶段，未锁定的玩家牌和敌方行动牌都可拖到空格。敌方牌按 BattleAction 身份移动，不依赖玩家 Card；移动不更换所属方、技能、效果、数字或必选行动身份。敌方牌拖回手牌区或落在区域外会还原。位置锁定、被动/内部结算行动不能拖动，跨越锁定位置仍由运行时规则拒绝。移动后的 BoardSlot 使用现有存档字段保留。

玩家手牌区标题和拖放文字提示隐藏；卡面效果说明与抽牌堆、弃牌堆入口保留。

接入位置：CardModule.CanMoveAction / MoveActionInBoardSlot / RepositionAction；BattlePanelView 绑定双方行动拖动；HandCardDrag 保留行动引用并限制玩家撤回。
