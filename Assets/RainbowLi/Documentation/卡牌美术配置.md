# 卡牌美术配置

场景和 PokerCard 预制体使用 `Data/DefaultCardSkins.asset`。其中配置了 `Art/卡牌无铭刻` 的36张裁切Sprite：3种花色 × 1～6点 × 蓝色玩家/红色敌人。沿用素材原有GUID和切片，未修改或重命名原图。

在 Inspector 中可按 number、enemy、suit 更换任意牌面。enemy勾选代表敌人红牌，不勾选代表玩家蓝牌。attackSuit、guardSuit、effectSuit分别决定攻击、防御、其他效果使用哪套花色，默认1、2、3。颜色归属始终由真实卡牌阵营决定，和正面/负面效果的目标无关。

新图片已包含数字、花色和说明框，所以旧的数字文字、花色图标、底栏贴图不再重复绘制。动态效果说明使用白色文字放在图片内置底栏，铭刻仍叠加原有标记。图片保留原比例，使用默认UI材质和白色，不再经过旧纸纹材质或红蓝染色。

手牌、敌人技能、行动条、悬停放大、飞牌、奖励、卡组/牌堆列表与二次确认共用CardView配置。未提供铭刻专用图片时，使用同阵营、点数的基础图片加铭刻标记。

修改入口：
- `Scripts/Unity/Data/CardSkinCatalog.cs`：按阵营、点数、效果类别选择Sprite。
- `Scripts/Unity/Views/CardView.cs`：绑定新皮肤、隐藏旧叠加内容。
- `Editor/CardSkinSceneMigration.cs`：菜单 RainbowLi > UI > 替换红蓝卡牌美术；会保留已有配表图片。
- `Editor/ArtBattleSceneMigration.cs`：后续重用战斗UI迁移时会沿用这套牌面，不会恢复旧纸纹。
