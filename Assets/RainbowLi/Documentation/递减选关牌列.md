# 递减选关牌列

每完成一关，只有所选列少一张卡。完成的卡牌隐藏，后面的卡在原位置显露；不会把后关持续移动到底部，也不会清空一列后自动补一张战斗卡。其他两列数量与位置保持原样。

`RouteMapView.Position` 为独立牌列按原始顺序固定位置；整列卡牌全部显示，`diagramBackCards × diagramStripHeight` 控制背牌总高度。卡牌较多时仅压缩背牌间距，避免卡片超出 CRT 区域，移除卡片时不重新压缩。

`RouteRun.Complete` 继续记录已完成关卡、战斗数量和 BOSS 解锁；BOSS 切换新大层时照旧生成新地图。原有 `EnsureBossRouteBattles` 仍在开局确保地图包含足够战斗，维持 BOSS 解锁保障。存档继续保存既有地图与 Completed 列表，无需新版本。
