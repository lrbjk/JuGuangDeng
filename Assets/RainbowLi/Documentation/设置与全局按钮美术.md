# 设置与按钮美术

场景 `Assets/RainbowLi/Scenes/RainbowLiGame.unity`。

菜单 `RainbowLi > UI > 统一设置与全部按钮美术` 在当前场景增量应用，保留按钮对象、事件与各自启用状态。

- 设置窗口使用 Art 中“大框”和“界面名称”，音量滑条使用“小框1”及“卡组/滑键”。设置逻辑、自动保存和返回菜单行为保持原样。
- 普通操作按钮使用“公共按钮”的九宫格，不放大边角；字体随按钮区域适配。
- 已有专用贴图的按钮保留贴图，统一鼠标悬停、键盘选中、按下、禁用反馈。
- 主界面独立发光按钮保留现有发光逻辑。
- 卡牌、牌序、路线节点、牌组行保留内容专用的画面和交互；不套用普通操作按钮背景。
- 动态按钮从已有场景模板克隆，会继承贴图和状态；相关 Prefab 同步处理。

`RainbowLi > 场景预览 > 设置界面` 可临时打开设置。预览后使用主界面预览关闭弹窗，避免将打开状态保存为游戏初始状态。

验证入口 `RainbowLi.EditorTools.UnifiedUiArtVerification.Run`（批处理不要加 `-quit`）。验证覆盖全部按钮对象与事件、内容图案、鼠标/禁用样式配置、动态克隆、音量滑条、播放速度、震屏和返回菜单。测试偏好使用独立键并在退出时清理。
