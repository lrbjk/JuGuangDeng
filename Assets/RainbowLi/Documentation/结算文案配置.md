# 结算文案配置

来源为策划《结算画面文案.docx》，成功、失败标题及三段正文原样接入。

选中 `Assets/RainbowLi/Data/DefaultEndScreenCopy.asset`，可分别修改 Success Title/Body 和 Failure Title/Body。正文支持换行；空行分段。配置绑定在场景 GameView 的 EndPanelView.copy，后续编辑该资产即可，无需改代码。

正文、标题、局内战斗/卡组统计分开显示。再来一局和返回主菜单操作保留；只有冒险最终成功/失败进入结算页面时才显示对应文案。重新应用战斗美术不会覆盖已编辑的文案资产。

程序入口：`Scripts/Unity/Views/EndPanelView.cs`；样式布局：`Editor/EndScreenCopySceneMigration.cs`。菜单 `RainbowLi > UI > 接入结算画面文案` 可重新应用布局。
