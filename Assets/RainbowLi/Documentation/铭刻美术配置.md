# 铭刻美术配置

配置资产：`Assets/RainbowLi/Data/DefaultEngravingArt.asset`。

## 策划怎样换图

1. 在 Project 选中 `Data/DefaultEngravingArt`，展开 Entries。
2. 找到相应的铭刻名称，将 `Art/铭刻/铭刻` 的 Sprite 拖到 Frame。
3. Name 是识别名称；Effect Id 对应铭刻效果表 ID；Effect 是兼容旧数据的铭刻行为。通常只需更换 Frame，不需修改 ID 和行为。
4. 所有卡牌共用此资产，修改一次即可影响手牌、行动区、卡组、抽弃牌堆、确认弹窗、悬停大图及飞行动效。

目前按用户确认的规则：素材文件名字典序对应现有铭刻效果表顺序，共 19 种。素材均为透明的蓝色边框与顶部菱形，沿用原图颜色；敌人卡牌底图仍为红色。没有铭刻的卡牌隐藏边框。旧存档只有铭刻标记、没有具体行为时使用追击边框，兼容原有含义。

原始 PNG 与 Sprite 裁切设置均不改变。显示时按素材与牌面的源图坐标对齐，保留顶部菱形外伸，不把边框拉伸到牌面里。

## 场景与程序入口

- `CardView.engravingArt`：共享美术配置；`Bind` 的可选 `engraving` 参数传入具体运行时铭刻，不能只传是否铭刻。
- `CardView.SetEngraving`：选择边框、对齐裁切坐标、隐藏无铭刻边框。
- `EngravingArtCatalog.Find`：先按效果 ID，找不到时按铭刻行为匹配；旧数据回退至 Legacy Effect。
- `CardMotionController.Visual`：保留铭刻快照，飞行、攻击牌沿用原卡边框。
- 菜单 `RainbowLi > UI > 配置铭刻卡牌美术`：给当前 RainbowLi 场景和 PokerCard 预制体接入共享配置；已有手动指定的 Frame 会保留。重新应用红蓝卡面时也会保留铭刻配置。

更改铭刻结算数值仍在原铭刻效果表中进行，本资产只管美术对应关系。
