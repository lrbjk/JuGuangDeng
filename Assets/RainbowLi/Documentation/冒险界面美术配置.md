# 冒险界面美术配置

场景：`Assets/RainbowLi/Scenes/RainbowLiGame.unity`。
素材：`Assets/RainbowLi/Art/GJ 各种ui`。

## 本次界面

- 奖励：三种奖励任选一种。卡牌生成进入原有选卡列表；铭刻进入卡组选择未铭刻的牌；牌序效果进入确认弹窗，领取后加入备用效果列表。确认后消耗当前奖励批次，取消不消耗。敌人配表独立结算的金币等固定奖励继续保留。
- 卡组：六列布局、竖向滚动条、菱形滑块，详情及升级、铭刻、删除继续使用二次确认；抽牌堆、弃牌堆也共用这个界面。卡牌沿用真实点数、效果、玩家蓝色卡面、白色说明文字和铭刻边框。
- 牌序调整：三行面板，每行三个数字、两个装备效果槽、两行横向滚动的备用效果。选关中点击数字调整；商店中购买效果、休息中重构数字沿用原规则。
- 商店：定向生成、升级、铭刻、购买牌序效果四个入口。价格来自配表，不使用示意图固定的 100。定向生成先选数字；升级和铭刻先选卡再确认。
- 休息：恢复、删除、激发（原随机生成卡牌服务）、重构（随机牌序数字），共用一次休息服务。删除和激发需确认。
- 左栏：已完成关卡、计时、敌人全局增益、金币、卡组数量、生命和玩家牌序均使用实时数据。

## 场景里在哪里改

- `GameView` 的 `AdventureUiArtView`：五类界面的按钮、标题图片、价格文字及设置入口引用。
- 各界面的 `ArtSidebar` 对象：`AdventureArtSidebar` 负责更新左栏数据；子对象的 RectTransform 可直接编辑位置。
- `DeckManagementPanel`：卡组背景、标题、`CardGrid`、滚动条、退出按钮和确认弹窗。排列参数在 `DeckOperationView` 的 Columns、Gap、Padding、Maximum Card Scale。
- `SequenceAdjustmentPanel`：牌序背景切片、三行控件、备用效果 ScrollRect。`SequenceEditorView` 的 Effect Width/Height/Gap、Reserve Rows 控制备用效果布局。
- `ServicePanel`：商店与休息的共用容器；`ArtBuyCards`、`ArtBuyRules`、`ArtRebuild` 为新入口，原升级、铭刻、删除、恢复、生成按钮继续复用。
- `RewardPanel`：三个奖励入口及退出（跳过奖励）按钮。只有敌人奖励配表允许跳过时，退出按钮才可点击。

美术按钮的原 PNG 不修改。新增 `UiButton` Sprite 表示可点击区域，`ArtSoftGlow` 子对象显示原图完整光晕，避免透明边距使按钮互相挡住。牌序大图按美术已有 16 个 Sprite 切片重组，不拉伸单个文字切片。

## 程序接口与配置

- `ContainmentGame.TakeEngravingReward(Card)`：免费为指定卡牌铭刻，验证卡牌属于当前牌组且未铭刻，再消费一次奖励批次。
- `ContainmentGame.TakeSequenceReward()`：按奖励牌序池生成备用效果，再消费一次奖励批次。
- `ContainmentGame.TakeReward(int)`：原选卡入口，与上述方法共用奖励批次消费流程，保留多批战利品和 BOSS 换层。
- `DeckOperation.RewardEngrave`、`RewardSequence`：新增的卡组操作模式，保留确认、取消与状态过期检查。
- 价格：原 GameDefinition 配表；铭刻、牌序内容和权重仍在原效果表及效果池配置中。
- 存档：继续使用既有奖励批次和卡牌数据，不新增存档版本；取消确认不修改随机数或奖励。

重新应用美术：打开 RainbowLiGame 场景，菜单 `RainbowLi > UI > 应用冒险界面美术（奖励卡组牌序商店休息）`，保存场景。重新应用会恢复这套标准布局，手工调整布局前请保留需要的改动。
