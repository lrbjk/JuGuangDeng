# 牌序调整界面

在 `Assets/RainbowLi/Scenes/RainbowLiGame.unity` 运行游戏。选关左侧点击任意玩家牌序，即可进入调整界面，三组牌序同时显示，左侧关卡进度、时间、敌人增益、金币和卡组入口保留。

## 玩家操作

- 前、中、后三个数字：点击对应数字，在 0～6 之间轮换。0 表示未设置，含 0 的牌序不能触发效果。
- 点击“效果 1”或“效果 2”的槽位，再点击该行备用效果，即可装备指定效果。金色槽位表示当前操作目标。
- 效果 2 可以为空；右上角 × 移除第二个效果。效果 1 保留一个效果，不能清空。
- 每行备用效果拥有独立的横向滚动列表和滚动条，可拖动或使用滚轮浏览。列表读取本局 `Player.AvailableEffects`，获得新效果后自动扩展，不限于四个。
- 顺子、三同号等要求显示在效果说明中。数字不满足要求时，已装备槽位显示“当前数字不满足条件”。
- 修改立即应用于本局，退出返回选关，不进入战斗、不消耗金币。需要写入存档时，点击左侧“保存”。战斗、奖励等其他阶段不能打开调整页；开始新局或进入战斗时自动关闭旧页。

选关和战斗中的牌序摘要只展示，数字及切换效果按钮不再提供直接修改。商店购买效果、休息随机重构也先进入本界面，再点击对应行的服务按钮执行；金币与一次休息服务限制沿用原规则。在休息、商店打开本界面时，自由调整数字和装备备用效果暂不可用；退出回到原服务界面，返回选关后再进行自由调整。

## 策划编辑位置

打开场景，在 Hierarchy 中展开：

`GameCanvas/Table/MapPanel/BannerRoute/SequenceAdjustmentPanel`

此对象默认隐藏，编辑布局时可临时勾选 Active，完成后取消。所有控件为原生 UGUI，支持在场景中修改 RectTransform、颜色、字体、文字大小和按钮样式。

- `SequenceRow_0/1/2`：三行牌序。
- 每行 `Numbers/Digit_0/1/2`：前、中、后三个数字。
- `EquippedEffects/PrimarySlot`、`SecondarySlot`：两个已装备效果槽。
- `EquippedEffects/RemoveSecondary`：移除第二效果按钮；`ServiceAction`：休息或商店的付费/限次服务按钮。
- `ReserveEffects/Viewport/Content/EffectTemplate`：备用效果模板，默认隐藏；运行时复制此模板展示本局可用效果。调整模板字体与颜色会应用于每个备用效果。
- `ReserveEffects/HorizontalScrollbar`：备用效果横向滚动条。
- `Instruction`：操作提示；`Exit`：退出按钮。

`GameCanvas` 上的 `SequenceEditorView` 配置备用效果宽、高、间距、边距及选中颜色。三个行的数字、效果槽与滚动区引用均已序列化。移动整行或整列请编辑其父对象，而不是修改脚本坐标。

## 程序接入位置

- `Scripts/Unity/Views/SequenceEditorView.cs`：界面打开、关闭、选槽、备用效果列表和刷新。`Open(int index)` 允许选关、休息、商店阶段；后两者只能执行该阶段服务，其他阶段禁止打开。`SelectSlot(int rule, bool secondary)` 选择目标槽；`ChooseEffect(int rule, int availableIndex)` 装备备用效果。
- `Scripts/Unity/Systems/SequenceModule.cs`：`CanAdjust` 检查调整页打开且处于选关阶段；`ChangeDigit`、`EquipEffect` 等手动调整入口关闭界面后不生效。
- `Scripts/Domain/ContainmentGame.Sequences.cs`：`EquipSequenceEffect(int index, bool secondary, int availableIndex)` 指定效果池索引，第二槽传 -1 移除；检查阶段与索引，完整复制效果配置，不共享可变对象。不新增存档格式，继续使用已有牌序和可用效果池保存逻辑。
- `AdventureMapHudView.cs`、`BattlePanelView.cs`、`SequenceView.cs`：摘要保持只读。选关左侧摘要根 Button 绑定 `SequenceEditorView.Open`。
- `ServicePanelView.cs`：休息、商店的牌序按钮只调用 `SequenceModule.OpenAdjustment`，不会在原界面直接重构或购买。调整页中的 `ServiceAction` 再调用原服务方法，且 `SequenceModule.Rebuild`、`BuyEffect` 要求调整页打开。
- `Editor/SequenceEditorSceneMigration.cs`：菜单 `RainbowLi/UI/接入独立牌序调整界面`。已完成场景接入，无需再运行。重新运行会重建调整页的默认布局，覆盖该页的手工布局，请仅在需要重新生成时使用。

效果库仍由原牌序配表与奖励/商店效果池提供，本次没有另建一份配置数据。三组牌序展示同一个已获得效果库，装备不消耗备用效果。
