# 卡牌效果二级界面

卡牌悬停详情使用 `Art/GJ 战斗ui分解/二级ui.png`；素材外围包含透明发光区，标题和正文分别放在内部对应框中。卡牌基础效果、铭刻条件/对象/数值沿用 Card.RulesText。卡组、手牌、双方行动牌共用 GameView.tooltip。

场景 `RainbowLiGame.unity` 中选择 `GameView/CardTooltip`：Image 可替换背景 Sprite，Title/Body 可调整文本样式；TooltipView 的 Art Width 默认720，包含外发光宽度。正文较长时窗口自动增高；窗口靠近屏幕边缘时保持完整可见。所有图文都关闭 Raycast Target，不影响卡牌拖动、悬停和点击。

程序入口：`Scripts/Unity/Views/TooltipView.cs`。重新套用素材：菜单 `RainbowLi > UI > 应用卡牌效果二级UI`。该菜单保留当前字体资产，不更改卡牌效果数据或游戏结算。

背景采用九宫格拉伸，固定标题栏、边框与外发光的厚度，只延展正文中央区域。原图内容不改动，仅在纹理导入器设置Sprite Border。
