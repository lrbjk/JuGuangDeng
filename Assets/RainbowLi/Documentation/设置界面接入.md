# 设置界面

开始、选关和战斗使用同一个原生 UGUI 设置弹窗：`GameCanvas/SettingsOverlay/Dialog`。

- `Volume`：音量滑条。独立 `FillArea/Fill` 与 `HandleArea/Handle`，滑条填充和滑块不超出轨道。
- `VolumeValue`：当前音量百分比。打开时读取实际战斗音频音量，不重置；拖动即时生效。
- `SpeedValue`：实际播放速度；`Speed` 按钮按现有规则切换 1 / 2 / 4 倍。
- `Close`：返回原界面。也可按 Esc 关闭。背景遮罩阻挡点击穿透。

策划可在上述场景节点修改布局、文字和颜色。`SettingsPanelView` 在此弹窗上，负责音量与速度显示；开始页、战斗 HUD 都引用同一个弹窗。开始页介绍、制作人员、风味文本保持原场景内容。

创建工具：`Editor/SettingsSceneMigration.cs`，菜单 `RainbowLi/UI/修复并统一设置界面`。已有统一弹窗时只重新绑定入口，不重建布局。音量、播放速度与震屏通过独立 PlayerPrefs 保存，重启后恢复；详见 `菜单与设置持久化接入.md`。游戏内设置提供返回菜单。
