# 游戏开始界面

场景：`Assets/RainbowLi/Scenes/RainbowLiGame.unity`。展开 `GameCanvas/StartMenuPanel`，开始页默认启用。没有游戏标题，主区域仅放介绍正文。

直接编辑以下原生 Unity Text 的 Text 字段，运行时不会覆盖文案：

- `IntroductionArea/Viewport/IntroductionText`：游戏介绍，支持换行与垂直滚动。
- `Sidebar/Credits/Text`：制作人员名单。
- `Sidebar/Flavor/Text`：风味文本或世界观。
- `ManualOverlay/Dialog/Text`：教学内容。

`GameCanvas` 上的 `StartMenuView` 保存引用；字体、字号、颜色和 RectTransform 均可在场景编辑。介绍区 ContentSizeFitter 按文本高度扩展，ScrollRect 和右侧滚动条用于长文本。

底部设置可调整音量及战斗播放速度；开始按钮创建新局并进入选关；退出按钮退出构建后的程序（Unity 编辑器内 Application.Quit 不关闭编辑器）。菜单期间不累计本局已用时间。选关页保留保存／继续入口，开始页新增读取存档，返回菜单后可继续当前局；详见 `菜单与设置持久化接入.md`。

程序位置：`Scripts/Unity/Views/StartMenuView.cs`；计时暂停由 `GameSession.PauseElapsedTime` 控制。场景创建工具为 `Editor/StartMenuSceneMigration.cs`，菜单 `RainbowLi/UI/接入游戏开始界面`；已存在开始页时保留现有文本与布局。
