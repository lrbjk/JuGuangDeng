# 三列独立关卡推进

选关界面始终按左、中、右三个独立卡堆显示。完成一张关卡后，仅将同列后面的第一张未完成卡补到前方；其他两列不移动、不作废，玩家下一次可选择任意列的前牌。不能跳过前牌选择后牌。

配置：`Assets/RainbowLi/Data/DefaultLevels.asset`，或菜单 `RainbowLi/关卡/关卡编辑器`。开启“三列独立关卡”。固定路线节点的列为 0、1、2，行号表示各列内部先后顺序；不需要连线。随机路线强制生成三列。修改后重新开始游戏生效。

接口：`RouteGraph.IndependentStacks` 标识模式；`RouteRun.FrontNode(lane)` 获取某列前牌，`CanEnter(id)` 校验进入，`Complete()` 完成并推进对应卡堆。`LevelModule` 保持战斗、休息、商店、事件结束后完成关卡的既有调用。

存档新增 `RunSave.RouteIndependentStacks`，三列进度由 Completed 与 RouteNodes 恢复；旧存档保留原路线模式。BOSS 仍在完成 5 + 冒险大层数场战斗后独立解锁，可随时进入。如果某列提前耗尽且 BOSS 尚未解锁，仅给该列补一个战斗关卡，防止无法继续解锁。
