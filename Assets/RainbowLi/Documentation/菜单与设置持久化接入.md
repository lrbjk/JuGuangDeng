# 菜单与设置持久化

开始页增加读取存档入口和返回菜单后的继续本局。新游戏与读取存档在已有当前局时弹出替换确认，取消不改当前局；损坏存档读取失败仍保留当前游戏。继续游戏使用第一位程序原有 `GameSession.ContinueGame()`，不新增存档字段。磁盘没有存档时禁用继续游戏。

游戏内设置的“返回菜单”保留当前局，同时暂停计时、自动结算和表现时钟。菜单“继续本局”恢复该局；关闭程序后需要使用已保存的磁盘存档。返回菜单不会自动保存。

设置使用独立 PlayerPrefs 键 `RainbowLi.Settings.Volume/Speed/Shake`，每次修改即时保存，下次启动读取。播放控制区修改倍速也会保存。玩家关闭震屏不会修改策划动效资产；实际震屏还受策划 profile 开关限制。非法浮点数恢复默认，合法数值限制在允许范围。

策划场景编辑位置：

- `GameCanvas/StartMenuPanel/Actions/Continue`：读取存档。
- `GameCanvas/StartMenuPanel/Actions/Resume`：返回菜单后继续本局。
- `GameCanvas/StartMenuPanel/ReplaceRunConfirmation/Dialog`：替换当前进度确认。
- `GameCanvas/SettingsOverlay/Dialog/Shake`、`ShakeValue`：震屏设置。
- `GameCanvas/SettingsOverlay/Dialog/ReturnMenu`：返回菜单。

介绍、制作人员和风味文本保留原场景内容。

程序：`Scripts/Unity/Views/StartMenuView.cs`（菜单流程）；`SettingsPanelView.cs`（设置操作）；`Scripts/Unity/Settings/GameSettings.cs`（持久化）；`BattleModule.cs`（菜单期间暂停表现与结算）；`BattleEffects.cs`（玩家震屏开关）。不改 Domain 与 GameSession。创建工具 `Editor/MenuSettingsSceneMigration.cs`，菜单 `RainbowLi/UI/接入菜单流程与设置保存`；重复接入不会重建已有新增控件。
