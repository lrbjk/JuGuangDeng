# 选关美术配置

场景：`Assets/RainbowLi/Scenes/RainbowLiGame.unity`。

- 素材：`Art/选关`。`背景2` 为选关专用背景；BOSS 未解锁、已解锁图片和进度条、格子、打勾均接入真实冒险状态。
- 卡片：当前素材没有单独提供灰色关卡卡面，使用 `选关ui 1.png` 的 `RouteCard` Sprite 子区域，原 PNG 不修改。关卡类型图标、名称仍由关卡配置决定。之后可以在 `RouteSelectionCard.prefab` 的 `RouteCardArtwork` Image 中更换独立卡面。
- 布局：GameView 的 `RouteMapView`，卡片 212×286、露出条高 61、列间距 110，最多显示 5 张后续卡。三列独立补位逻辑不变。
- BOSS：GameView 的 `AdventureMapHudView` 可更换 Boss Locked/Unlocked Sprite、Marker Sprite 和 Check Sprite。未解锁时按本层已完成战斗打勾，达到 `5+冒险大层数` 后隐藏进度条、切红色入口。已完成关卡与累计战斗统计不设总次数上限。
- 左栏：关卡次数、计时、敌人全局增益、金币、牌组均为实时数据；保留新的一局、保存、继续、牌组查看、玩家牌序调整、设置入口。
- 编辑器重新应用：打开 RainbowLiGame 场景，菜单 `RainbowLi > UI > 应用美术选关界面`，保存场景。该菜单只修改选关表现，不生成新的冒险数据。
