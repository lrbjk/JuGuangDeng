# 主界面美术

场景：`Assets/RainbowLi/Scenes/RainbowLiGame.unity`。

素材：`Assets/RainbowLi/Art/GJ 各种ui/主界面/`。使用“主界面背景”及独立按钮；“主界面.png”是美术效果参考，不用于覆盖交互。

## 布局与编辑

- `GameCanvas/StartMenuPanel` 随 Canvas 拉伸。
- `Sidebar` 固定为 442 个设计单位宽；背景纵向九宫格拉伸。制作人员与风味文案继续编辑 StartMenuView 引用的 Text。
- `ArtMainSurface` 填充右侧剩余空间，背景用九宫格保持屏幕边框厚度。
- 介绍区域保留 ScrollRect，文字随区域宽度换行，长文可以滚动。
- 四个主要按钮沿右侧底部均匀排列，按钮尺寸和字体保持比例。亮图的外发光不扩大按钮点击范围。
- 教学手册位于左侧底部；“继续本局”位于右下角，保留与“继续测试（读取存档）”的区别。
- 共享的 `SettingsOverlay` 保留在 GameCanvas 下，菜单关闭后战斗仍能打开设置。

菜单：`RainbowLi > UI > 应用主界面美术到当前场景`。重复执行保留按钮引用、监听与文案，不重复生成节点。

此适配仅覆盖主菜单和其弹窗；战斗、选关等已有布局未整体重排。

## 验证入口

Unity 批处理执行 `RainbowLi.EditorTools.MainMenuArtVerification.Run`，不要加 `-quit`（验证会自行退出）。

验证会检查引用与文案保留、重复应用、悬停和禁用状态、设置/手册开关、开始/恢复/替换当前进度，并在 `Assets/RainbowLi/Verification~/MainMenuPreview/` 输出 1920×1080、1280×720、1920×1200、2560×1080 四种预览。验证不保存预览相机及临时显示状态，不写入游戏存档。
