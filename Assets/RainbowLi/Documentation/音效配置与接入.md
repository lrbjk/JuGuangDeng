# 音效配置与接入

配置依据：`Art/音效包/音效对应文档.docx`。原始音频保留在 `Art/音效包/音效`。

## 策划调整位置

在 Project 中选中 `Assets/RainbowLi/Data/DefaultGameAudio.asset`，展开音效条目，可直接替换 Clip、修改 Volume 和 Pitch。音效类型在 Inspector 中使用中文显示。minimumInterval 控制同类音效的最短间隔，默认 0.025 秒；场景切换、开始按钮和死亡提示不会被这个间隔吞掉。

场景 `Assets/RainbowLi/Scenes/RainbowLiGame.unity` 的 GameView 对象挂有 GameAudioController，Profile 指向上述资产。UiAudioSource 播放界面、飞牌与服务声音；BattleAudioSource 播放命中与效果声音。两个源均为 2D，受现有设置中的音量控制；战斗声音跟随暂停，界面声音保持可用。

## 文档对应关系

| 文件 | 触发位置 |
| --- | --- |
| 主界面按钮音效 | 主界面按钮、开始执行按钮 |
| 场景切换音效 | 主菜单进出、选关与各房间切换、冒险大层变化；规划与结算不是两个场景 |
| 点击音效 | 卡牌交互，抽牌抵达手牌、卡牌飞入弃牌堆 |
| 按钮音效 | 普通按钮，卡牌抵达行动条、调整位置、撤回 |
| 击杀音效 | 玩家或敌人死亡 |
| 受击音效 | 玩家或敌人受到伤害、护盾抵挡伤害 |
| 获得效果音效 | 双方获得状态、护盾、强化、治疗；商店交易、休息服务、事件选择完成 |
| 卡牌触发音效 | 卡牌或敌人技能效果发动 |
| 卡序触发音效 | 牌序效果发动 |

卡牌飞行动画结束后才播放抽牌、弃牌与放牌声音；被取消的飞行不会发出到达声。战斗声音从实际结算事件获取双方对象，在演出命中时播放，避免重复刷新导致重播。纯数字插入和内部结算完成标记不额外伪造卡牌触发声。快速结算时抑制大量连锁声音，死亡提示保留。

原有 BattleEffects 合成打击声在这套配置启用时停止播放，避免两种受击声音叠加；删除或禁用音效配置控制器时，旧打击声仍可作为回退。

## 程序接入位置

- `Scripts/Unity/Data/GameAudioProfile.cs`：九类音效和可编辑参数。
- `Scripts/Unity/Effects/GameAudioController.cs`：场景、服务、战斗事件与音量。
- `Scripts/Unity/Views/AudioUiFeedback.cs`：按钮和卡牌交互，克隆按钮同样有效。
- `Scripts/Unity/Effects/CardMotionController.cs`：飞牌完成时触发。
- `Scripts/Unity/Effects/BattleEffects.cs`：命中时触发，并避免旧音效重复。
- `Editor/GameAudioSceneMigration.cs`：菜单 RainbowLi > 音效 > 按音效包文档接入当前场景。重新绑定会保留已调整的音频、音量与音调。

## 背景音乐（已接入）

选择 `Assets/RainbowLi/Data/DefaultGameMusic.asset` 调整背景音乐：

- `Map`：主菜单、选关、商店、休息、事件、奖励及结束界面的音乐，默认“选关.mp3”。同一曲目跨界面连续播放。
- `Enemies`：按敌人运行时 ID 前缀匹配。默认机械类、生物类、抽象概念类，每类分别配置 Normal 普通/精英战斗音乐与 Boss 音乐，共6首。
- 可以新增更长前缀或完整敌人 ID，覆盖某一个敌人的配乐；最长匹配优先。未知分类或未填写曲目时回退 Map。
- `Volume`：音乐相对音量，默认0.65，最终乘设置里的总音量。总音量调为0时静音但保留播放进度。
- `Fade Seconds`：换曲交叉淡入淡出，默认0.6秒，0为立即切换。

场景 GameView 上的 `GameMusicController` 引用配置资产和现有 `GameAudioController`。子对象 `BackgroundMusicA/B` 是专用2D循环音源，交替淡入淡出，不与按钮和战斗音效共用。同曲不会因卡牌刷新、回合切换、查看卡组重播；战斗暂停、单步、跳过和播放倍速不影响音乐速度。退出战斗改为选关音乐，返回主菜单同样使用选关音乐。

程序修改入口：`Scripts/Unity/Data/GameMusicProfile.cs`（配置和匹配）、`Scripts/Unity/Effects/GameMusicController.cs`（循环播放、淡入淡出及音量）。菜单 `RainbowLi > 音效 > 接入背景音乐` 可为当前 RainbowLi 场景重新挂接；已有配置资产的策划改动会保留。运行时音乐来源从当前敌人读取，因此读档进入战斗也会按恢复的敌人分类播放。
