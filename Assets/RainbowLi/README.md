# 数字收容：玩法原型

## 运行

在 Unity 6000.3.12f1 中打开此项目，双击 `Assets/RainbowLi/Scenes/ContainmentPrototype.unity`，按 Play，然后在 Game 视图操作。推荐 1440×900 或 16:10；其他尺寸按比例缩放。

1. 在任务选择页点击上方三张牌序卡的数字，循环 1–6。
2. 进入战斗，点击手牌选中，再点击行动之间的 **+** 插入，每回合最多四张。再次点击选中手牌可取消选择。
3. 用左右箭头移动玩家或实体行动；× 只能移除玩家牌。把护盾排在实体攻击之前，或拼出三位数字牌序。
4. 左侧实时预览这一回合的双方生命，上方亮起的牌序卡表示预计能够触发，并标注次数。
5. 点击开始执行，按约一秒一项播放；当前行动与触发牌序高亮，显示攻击方向和生命、护盾的实际变化。可暂停并执行下一步。
6. 胜利获得金币，从三张生成卡中选择一张。两次普通战斗后可挑战 Boss。

## 新版战斗表现

### 扑克牌与动效

绿色牌桌与奶油色圆角纸牌，带阴影、双向角标和对应数字的花色点数；冲击用方块、屏障用黑桃、修复用红心，敌方用梅花。花色为表现标识，不增加额外战斗规则。

- 每回合手牌以 0.07 秒间隔滑入，略呈扇形。
- 悬停弹性抬升并随鼠标轻微倾斜；选中抬起并出现金色边框。
- 出牌在 0.42 秒内沿弧线飞向指定行动位置。
- 行动结算有卡牌震动、受伤生命条闪白与震动、数字弹跳和淡出飘字。
- 牌序触发有扩散金色光圈和提示；奖励卡缓慢摆动。
- 普通行动保留观察时间，连续牌序触发会逐渐加快，长连锁无需等待数分钟；手动单步仍可逐项查看。
- 选牌、落牌、触发使用运行时合成的轻量提示音。

动效使用不受 Time.timeScale 影响的时间和阻尼弹簧，无需额外安装插件。点击范围保持固定；暂停播放时，卡牌反馈仍继续完成。

整体按 [参考画面](https://www.nintendolife.com/reviews/switch-eshop/balatro) 重排：左侧固定状态栏，绿色开放牌桌，上方三张牌序卡，中央竖向行动牌，下方扇形手牌与右侧牌堆。生命与护盾使用红蓝数值格，数字为 5×7 点阵，按钮有厚边与投影。扑克牌面只保留数字角标和花色点数，卡效放在牌外下方，避免横向面板式卡片。

中文直接加载项目内的 `Resources/RainbowLiChinese.ttf`，不再依赖运行机器的系统字体搜索。字体来自当前机器的 SimHei，Unity 已验证当前界面使用的全部 275 个汉字；花色使用程序生成的图形，避免花色符号缺字。点阵数字保持原样。

文本框会根据内容测量并调整字号，阴影缩小为一像素；商店与奖励区使用等比缩放，避免文字被横向压扁。

预览通过战斗模型的独立快照执行真实规则，包含插入数字、连锁、护盾和致死中断；不会消耗真实随机状态，也不会发放真实战利品。数字流过长时只显示前十二位及总长度。

## 已实现

- 三组 1–6 的随机基础卡组，共 18 张；每回合抽六张，弃牌堆循环洗回。
- 三种示例卡效：冲击、屏障、修复，基础数值为代表数字 +3。
- 全部敌人行动保留在时间线；玩家与实体逐项行动。
- 三位连续实际数字匹配，允许重叠。场地、玩家、实体牌序按顺序插入效果。
- 基础牌序：123 伤害 10；345 护盾 10；222 后续卡效 +2 并插入数字 2。
- 新数字参与连锁，每种牌序每回合最多触发 99 次。强化影响后续玩家卡效。
- 每场生成三组场地牌序，当前牌序累计触发两次后在下一回合轮换。
- 卡牌铭刻：用该牌收尾并触发牌序时，额外伤害 5，每张牌最多一次。
- 战斗奖励：25 金币、一次卡牌选择、20% 概率随机铭刻。
- 休息：恢复 24 生命、生成卡牌、指定删牌或重构牌序，任选一次；每次战斗胜利刷新可用次数。
- 商店：指定数字生成 15 金币、升级 +2 花费 12、铭刻 20、替换牌序效果 18。
- 普通实体与 Boss、失败和通关状态、重新开始。

## 原型约定与范围

策划未附卡效表与敌人文档，以上卡效、敌方技能、数值和费用均为示例，可在 `Scripts/ContainmentGame.cs` 中调整。

玩家和实体的数字都进入同一数字流。护盾与临时强化在回合开始清零。每回合剩余手牌也会弃置。这些是本版明确采用的规则，后续可以根据实际测试修改。

当前使用简单面板界面验证玩法，没有正式美术、音效、存档、路线生成或独立奖励节点。基础构建可修改数字；效果替换在商店进行。定向生成暂支持数字，尚不支持指定卡效池。战斗概率战利品暂只实现铭刻。

仅原型场景中的控制器启动玩法；所有提交文件在 RainbowLi 内。

## 验证结果

- Unity 6 自带 C# 编译器与 UnityEngine 程序集：包含新牌桌布局的四份运行时脚本编译通过。
- `Verification~/RuleChecks.cs`：39 项断言通过，新增指定位置插入、预览稳定性、无副作用、连锁及预览与实结算一致检查。
- 独立 Unity 6 批处理工程：场景加载、Awake 初始化及 Update 自动执行到第二回合通过，进程退出码 0。
- 空验证工程的 UnityEditor.Search 搜索索引出现编辑器内部异常；验证只排除该明确堆栈，其他运行时异常均视为失败。
- 新版 Windows 独立程序构建通过，自动驱动选牌、插入预览与执行场景后正常退出；没有玩法运行时异常。39 项规则检查通过。
- 后台截图没有得到有效画面，因此尚未完成图形窗口的视觉验收，需在 Unity Game 视图试玩确认。
- 中文字体专项检查：Unity 导入并加载项目字体成功，275 个中文字符均通过 `Font.HasCharacter` 检查，退出码 0。

`Verification~` 不被 Unity 当作资源目录导入；其临时编译产物与日志通过本目录 .gitignore 排除。

血条：左侧敌人面板红色血条、玩家面板青色血条显示当前/最大生命，受伤和治疗时随实际数值更新。右侧小数字框为护盾。卡牌旋转使用牌桌局部坐标，适配 Game 视图缩放与居中。

攻击表现：攻击牌冲刺、攻击轨迹、粒子命中爆发、血条闪烁、浮动伤害及冲击音效；伤害越大，震幅、粒子数量、爆发范围和数字越大，声音越低沉。护盾完全挡住时显示格挡。连锁攻击各自保留短暂动效，强度与事件数有上限。
