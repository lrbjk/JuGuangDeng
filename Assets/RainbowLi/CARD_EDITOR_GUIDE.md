# 玩家与敌人卡牌配表编辑器

Unity 顶部菜单：`RainbowLi > 配表 > 玩家卡牌编辑器` 或 `敌人卡牌编辑器`。也可以双击 `Data/DefaultPlayerCards.asset`、`Data/DefaultEnemyCards.asset` 直接打开表格窗口。两份资产已分别绑定到 DefaultPlayer、DefaultEnemy；场景入口仍为 `Scenes/RainbowLiGame.unity`。

## 与 Excel 一致的字段

前七列保持《卡牌效果.xlsx》的顺序与含义：效果编号、效果名称、效果类型（持续方式）、效果类型（性质）、对应效果池、基础取值范围（存在 X 时）、备注。原表第五列实际是效果描述，窗口也在这里编辑说明。

每行是一种卡牌效果或敌方技能。编号必须唯一；需要同一效果的多个敌方技能时，复制行并使用新编号。新增行默认复制基础伤害效果，修改“结算效果”下拉框决定实际逻辑。文字描述用于说明，实际结算使用持续类型、基础取值范围和结算效果字段。正面/负面/特殊用于配表分类，不能反转效果对象。现有 26 种结算逻辑全部可选。

作用对象由“结算效果”的行为决定，玩家和敌人共用同一规则：伤害、增值伤害、减值伤害、中毒、烧伤、流血、易伤、弱化和无序施加给对手；防御、恢复、力量及其余增益/数字操作作用于出牌者。点燃、淬毒先给出牌者对应增益，再在行动后向对手施加烧伤/中毒。已有中毒、流血在受影响者身上结算，会单独标注伤害来源。

基础取值范围支持 `1`、`1-2`、`为卡牌对应数字`。随机生成的 X 在卡牌生成时确定；敌方 X 在当回合意图生成时确定，预览与真正执行不会重新抽取。伤害、增值伤害、减值伤害依照表格公式处理数字。

右侧扩展列用于实际配置：

| 字段 | 用途 |
|---|---|
| 启用 | 决定这行是否进入该角色的卡牌池；关闭的行保留配置 |
| 数字 | 1–6；敌方填入牌序的数字，或玩家手工起始牌的数字 |
| 权重 | 大于 0；随机抽取这类效果的相对概率 |
| 起始牌 | 玩家是否允许在随机起始牌中生成；关闭后仍可能在奖励/商店中生成 |
| 特殊技能 | 敌方技能首次满足条件时额外执行，之后加入随机技能池 |
| 触发条件 / 阈值 | 回合达到阈值，或生命百分比降到阈值及以下 |
| 特殊权重比 | 0.3–0.7，乘基础技能平均权重；同一回合至多抽一种特殊技能 |
| 结算效果 | 对应现有 26 种实际效果；描述文字的修改不会自动创造新逻辑 |

备注仅供策划记录。玩家窗口隐藏敌人专属列，导出时仍保留完整字段。

## 编辑和保存

在窗口内直接编辑单元格，可搜索编号、名称或描述，也可只看已启用的行。先点左侧行号选中一行，再复制、删除或在底部编辑追加效果；行号左侧复选框用于多选。支持 Unity 的 Ctrl+Z / Ctrl+Y 撤销与重做。

点击“保存配表”校验并保存资产。点击“绑定到角色”将当前配表挂到所选 PlayerDefinition / EnemyDefinition；用“新建配表”可以为其他角色创建独立资产。角色系统的 Inspector 中也有 Card Table 引用。保存后重新开始游戏读取新配置，当前战斗的运行时快照不会被中途替换。

默认玩家表启用原表全部 26 种效果，优先于 CardSystem 的兼容 Catalog。随机起始牌仍为三组数字 1–6 共 18 张，数字列在这个模式下不改变分组。关闭玩家配置的 Random Starting Deck，则以每一行“启用 + 起始牌”的数字生成一张手工起始牌，至少需要 6 行；非数字 X 使用范围下限作为固定值，需要确定数值时填写单个整数。手工牌组模式下配表优先于旧 Starting Deck 引用。

默认敌人表保留基础伤害、防御和回合 3 的特殊重击，其他 24 行暂时关闭；勾选启用即可接入其他状态效果。绑定配表时使用表内的数字和 X，旧敌人配置的 Attack / Skills 作为未绑定配表时的兼容配置，Boss 血量、行动数、条件牌序继续使用 EnemyDefinition。

## Excel 导入、导出与粘贴

“导出 XLSX”生成可在 Excel 中继续修改的表，前七列与原表一致，右侧保留启用、权重及条件等扩展字段。导出包含关闭的行，第一行表头冻结。无需安装 Excel 或额外 Unity 插件。

“导入 XLSX”使用 Sheet1（没有 Sheet1 时取第一张表），先打开差异预览，默认按编号合并；只有勾选“XLSX 使用整表替换”才列出源表缺失的删除项，删除项默认不勾选。确认要应用的差异后才修改资产，预览和取消均不改变表。预览后当前资产如果被修改，必须重新预览。支持原始七列表格以及编辑器导出的十六列表格。导入原始表时，同编号行保留当前表已有的扩展设置；新增编号必须在扩展“结算效果”列指定现有效果。公式单元格需先在 Excel 中粘贴为值。

“粘贴 Excel 行”用于从 Excel 复制整行数据：先预览，再按编号更新或新增勾选的行；没有勾选的行保留原数据。可包含表头，至少复制原表七列。带换行、制表符的带引号文本也支持。若需要只新增同类效果，先修改编号；重复编号不会被默默覆盖。

导入、粘贴和编辑分别作用于当前选中的配表，玩家、敌人以及旧 CardEffectDefinition 资产不会互相修改。导入失败不改变当前表；所有解析失败的数据行与语义错误一起显示；XLSX 中的空白行也计入真实 Excel 行号。错误未修复不能应用，批量操作失败时整批不变。修改数据后仍需点击保存。

所有新增脚本、资产及说明位于 Assets/RainbowLi。已进行规则和 Unity 无图形批处理验证，未进行编辑器窗口的图形视觉验收。

## 多选批量编辑

1. 搜索或启用筛选后，勾选行号左侧的复选框；“勾选当前筛选”将当前可见行加入选择，“清空勾选”取消全部选择。筛选不会清除先前勾选。
2. 展开“批量编辑”，勾选准备修改的字段，填写新值。支持启用、起始牌、权重、数字、X 范围和主结算效果。
3. 点击“应用批量修改”。只修改勾选行的勾选字段；任何校验错误都会撤回整批。支持 Ctrl+Z / Ctrl+Y。
4. 点击“保存配表”。导入应用和撤销后选择会刷新，避免删除行后误改原行号对应的其他卡牌。

## 复合效果怎么配

点击主表行号，展开窗口底部“复合效果配置”。主表仍是效果 1，追加效果从 2 排列；每条分别配置启用、结算效果、持续方式、性质、X 范围和描述。使用 ↑ 调整顺序，最多追加 99 条。复制卡牌会深拷贝追加效果，不会改到原卡。

导出的 XLSX 有两个工作表：Sheet1 保留原七列和原十六列扩展；“复合效果”逐行配置追加效果。

| 复合效果表字段 | 填写方式 |
|---|---|
| 卡牌编号 | 与 Sheet1 的效果编号一致；导入主表中必须存在该卡 |
| 执行序号 | 2、3、4…连续排列；1 为主效果，同卡不能重号或跳号 |
| 结算效果 | 例如 Guard、Burn，使用导出模板的程序效果标识 |
| 持续方式 | 其他类型效果、临时性效果、持续性效果 |
| 性质 | 正面效果、负面效果、特殊效果；不改变实际对象 |
| 效果描述 | 策划说明，不解析为程序规则 |
| 基础取值范围 | 1、1-2、为卡牌对应数字 |
| 启用 | 1/0 或 是/否；关闭的效果仍保留并导出 |

原七列或旧十六列文件没有“复合效果”表时，保留同编号卡牌已有的追加配置。如果存在这个工作表，则以它为导入卡牌的追加效果配置；只有表头没有数据表示清空其追加效果。只复制主表行不会清空追加效果。

**当前实现了复合效果的配表、保存、导入导出及读取接口，尚未实现游戏内多效果结算。** 激活追加效果后，窗口会显示接入提示；现有单效果运行接口明确报错，避免悄悄忽略效果 2。当前默认玩家、敌人配表没有启用追加效果，正常游戏不受影响。

未接入核心时，实验数据保存在独立示例配表，不绑定默认角色；若要用单效果路径运行，先关闭追加效果的“启用”。菜单 RainbowLi → 配表 → 创建复合效果配置示例；示例资产位于 Data/Examples，已提供玩家“攻击后护盾”和敌人“攻击后烧伤”，不会自动绑定或修改原角色。
