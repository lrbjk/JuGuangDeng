# 策划摘录与实现选择

来源：C:/Users/31454/Downloads/玩法策划文档.pdf，9 页。

核心规则：三组 1–6 初始卡，共 18 张；回合抽六张；玩家最多安排四次行动，全部敌人行动需要安排。三位数字按实际执行顺序匹配；场地 > 玩家 > 敌人；新插入数字参与连锁；每种牌序每回合最多 99 次；增益影响后续行动；场地牌序达到条件后下回合轮换。

原型取舍：三个可编辑基础牌序；每场三个场地牌序，累计触发两次后下回合轮换。玩家与敌方数字均进入同一数字流。弃牌洗回抽牌堆；护盾每回合重置；金币、卡牌生成、一次铭刻、升级、删牌、恢复与 Boss 解锁均采用示例数值。无存档、正式美术、音效和完整内容配置表。

使用 IMGUI 原型面板，兼容项目仅启用新 Input System 的设置，无需新增依赖。

表现改版：敌方意图和实际卡效出现在行动卡上；点选手牌后按 + 指定插入位置；右侧用隔离状态快照显示精确结果与牌序触发次数；自动播放放慢到约每秒一步，显示方向、行动高亮和生命/护盾差值。

扑克牌动效版：绿色牌桌、奶油纸牌、花色角标与点数；阻尼悬停、选中弹性、扇形发牌、弧线出牌、行动震动、飘字与牌序光圈；提示音运行时合成。连续牌序自动加速，避免 99 次连锁以一秒一步播放过久。

布局还原版：以参考游戏截图为布局依据，将统计集中在左侧、牌序放在上方、行动牌置于中央，手牌在下方。扑克牌面去掉卡效和说明；卡效在牌外显示。数字使用 5×7 点阵并验证十个字形均为 35 格；中文字体只优先使用已安装的像素字体，否则回退。调整出牌终点与飘字坐标以适配新布局。

文字缺字修复：用户确认中文乱码/方框/缺字，改为随项目加载 SimHei TTF；字体文件和 Unity 资源加载均验证覆盖全部 275 个界面汉字。该字体不含四种花色，因此花色改为程序生成纹理。另修复文本自适应、过大阴影偏移及旧页面横向压缩。

模块迁移：已有 uGUI 2.0 和 Input System 1.19，采用原生组件且不改包。纯模型 partial 拆分保持共享状态/预测；Unity 组件用于场景编排，资产仅作模板。生成器首次 Sprite 导入模式 Multiple 导致花色为空，改为 Single 后真实场景引用与完整交互检查通过。Play 模式换场景后测试需重新获取运行时对象；同时禁止在非激活 CardView 上启动协程。CanvasScaler Expand 保持整个牌桌可见。


分支关卡交付：独立 RouteGraph/RouteRun、LevelDefinition/LevelModule 与地图/节点视图；默认 8 层 3 分支 22 节点，房间结束后沿连线前进。1885 项规则断言、550 项 Unity 场景检查通过。保留既有战斗 UI，仅追加地图与事件面板；无图形模式，未视觉验收。
