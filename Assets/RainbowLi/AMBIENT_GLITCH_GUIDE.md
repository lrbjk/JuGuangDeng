# 花屏策划配置

Unity 菜单：**RainbowLi → 表现 → 花屏配置**。

配置资产：`Assets/RainbowLi/Resources/AmbientGlitchProfile.asset`。游戏启动时自动加载，保存后会用于后续运行和打包。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| 最短间隔（秒） | 120 | 随机等待区间下限 |
| 最长间隔（秒） | 240 | 随机等待区间上限 |
| 持续时间（秒） | 0.65 | 单次花屏时长 |
| 花屏强度 | 0.9 | 横带错位和干扰强度 |
| 最大横向错位比例 | 0.14 | 横向撕裂距离相对于屏幕宽度的比例 |
| 噪点不透明度 | 0.75 | 雪花噪点可见度 |
| 图案变化频率（次/秒） | 24 | 花屏图案变化速度 |

把最短、最长间隔都设为 180，就是固定每 3 分钟触发一次。设为 120 和 240，则每次在 2–4 分钟之间随机等待。

修改参数后点击 **保存配置**。播放模式中可点 **立即预览一次花屏**，无需等倒计时；修改间隔会重新计时，其他参数在运行中应用。

增强版使用 14 条错位画面横带、4 条噪点带和 20 条扫描线，保留当前画面本色。使用真实时间，战斗倍速不影响间隔和持续时间。切出窗口会取消并清理当前花屏，恢复后重新等待。
